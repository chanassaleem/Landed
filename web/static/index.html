One customer, one code.

Data sanity can see that two codes look like the same hospital. This is where you decide. A mapping is applied when the files are read, never written into them, so the snapshots stay exactly as your system exported them and changing a mapping moves every past figure with it.

Mappings in force

—

—

These are the checks a row cannot fail on its own. They compare the files against each other and against what the rest of the file looks like, which is where the faults live that produce a dashboard that computes cleanly and is wrong. Nothing here is corrected automatically: silently fixing your data is how a product loses the right to be trusted.
